**Вьюпорт** — это ваш мир в центре редактора. Здесь вы летаете, выделяете объекты и меняете их положение.

## Камера

Зажмите **правую кнопку мыши** во вьюпорте, чтобы летать:

| Клавиша | Что делает |
| --- | --- |
| <Kbd>W</Kbd> <Kbd>A</Kbd> <Kbd>S</Kbd> <Kbd>D</Kbd> | вперёд, влево, назад, вправо |
| <Kbd>Space</Kbd> или <Kbd>E</Kbd> | вверх |
| <Kbd>C</Kbd> или <Kbd>Q</Kbd> | вниз |
| <Kbd>Shift</Kbd> | в три раза быстрее |
| колесо мыши (во время полёта) | изменить скорость полёта |

Другие клавиши для камеры:

| Клавиша | Что делает |
| --- | --- |
| <Kbd>F</Kbd> | подлететь к выделенному объекту |
| <Kbd>Home</Kbd> | вернуть камеру к вашему персонажу |

Скорость камеры по умолчанию задаётся в [настройках движка](/docs/latest/editors/settings): **Вьюпорт → Скорость камеры**.

## Закладки камеры

Удобное место можно запомнить и потом мгновенно туда вернуться:

- <Kbd>Ctrl+1</Kbd> … <Kbd>Ctrl+9</Kbd> — запомнить текущий вид в ячейку;
- <Kbd>1</Kbd> … <Kbd>9</Kbd> — перелететь к запомненному виду.

## Выделение

- **Клик** по объекту — выделить его.
- **Ctrl + клик** или **Shift + клик** — добавить объект к выделению или убрать из него.
- **Протянуть рамку** левой кнопкой по пустому месту — выделить всё, что попало в рамку.
- Клик по пустому месту — снять выделение.

Выделять можно и в панели **Сцена**. Там же видно, что именно выделено.

## Инструменты

У вьюпорта четыре инструмента. Они переключаются клавишами или через **Инструменты → Инструмент вьюпорта**:

| Клавиша | Инструмент |
| --- | --- |
| <Kbd>Q</Kbd> | **Выбор** — только выделять |
| <Kbd>W</Kbd> | **Перемещение** — стрелки по осям |
| <Kbd>E</Kbd> | **Поворот** — кольца вращения |
| <Kbd>R</Kbd> | **Масштаб** — изменить размер |

Потяните за стрелку, кольцо или кубик — объект сдвинется, повернётся или изменит размер. Точные числа можно ввести в панели **Детали**.

### Настройки гизмо

| Клавиша или пункт меню | Что делает |
| --- | --- |
| **Инструменты → Привязка к сетке** | двигать и поворачивать с шагом. Шаг задаётся в настройках движка. |
| <Kbd>T</Kbd> | переключить оси: мировые или оси самого объекта |
| **Вид → Центр вращения — центр выделения** | вращать группу вокруг её центра |
| **Вид → Прилипание к поверхности** | объект «прилипает» к блокам под курсором |
| <Kbd>End</Kbd> | опустить выделенное на землю |
| <Kbd>Del</Kbd> | удалить выделенное |

## Что показывать

| Клавиша | Что делает |
| --- | --- |
| <Kbd>G</Kbd> | **игровой вид** — спрятать все помощники редактора и посмотреть на сцену глазами игрока |
| <Kbd>H</Kbd> | скрыть выделенное во вьюпорте |
| <Kbd>Shift+H</Kbd> | изолировать — показать только выделенное |
| <Kbd>Alt+H</Kbd> | показать всё скрытое |

Скрытие работает только в редакторе — для игроков объекты никуда не пропадают.

## Предпросмотр камеры

Если выделить актёра **Камера**, в углу вьюпорта появится маленькое окно — «картинка в картинке» с видом из этой камеры. Включается в **Вид → Предпросмотр камеры**. Размер окна — в настройках движка.

## Гизмо вне редактора

Пропы можно двигать и без открытого редактора — прямо в игре:

| Клавиша | Что делает |
| --- | --- |
| <Kbd>K</Kbd> | включить или выключить гизмо |
| <Kbd>J</Kbd> | сменить режим гизмо |
| <Kbd>H</Kbd> | указатель гизмо |

Эти клавиши можно поменять в обычных настройках управления Minecraft, в разделе **StoryModEngine**.

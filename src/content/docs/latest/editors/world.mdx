Панель **Мир** собирает основные настройки мира в одном месте, чтобы не вспоминать команды. Открыть её — **Мир → Настройки мира**.

<Screenshot id="editors/world-panel" alt="Панель Мир с разделами настроек">
Панель «Мир»: раскрыты «Время», «Погода» и «Мир и режим», ниже свёрнуты «Точка спавна», «Граница мира», «Правила игры», «Пресеты», «Инфо и уборка».
</Screenshot>

> [!NOTE]
> Менять мир можно только с правами оператора (уровень 2). Без них панель работает в режиме просмотра.

## Разделы

| Раздел | Что там |
| --- | --- |
| **Время** | время суток (**Рассвет**, **Утро**, **Полдень**, **Закат**, **Ночь**, **Полночь**), скорость времени, включение смены дня и ночи |
| **Погода** | **Ясно**, **Дождь**, **Гроза**, длительность, включение смены погоды; ветер для эффектов (сила, направление, порывы) |
| **Мир и режим** | режим игры (**Творческий**, **Выживание**, **Приключение**, **Наблюдатель**), сложность и её блокировка |
| **Точка спавна** | координаты и поворот спавна; кнопки **Спавн с игрока** и **Спавн с камеры**; радиус спавна |
| **Граница мира** | центр и размер границы; **Центр с камеры**; кнопка **Убрать** |
| **Правила игры** | все правила игры с поиском; отдельно видно, какие правила вы изменили |
| **Пресеты** | сохранить текущие настройки мира под именем и применить их позже |
| **Инфо и уборка** | сид, измерение, сколько игроков, сущностей, животных и предметов; кнопки **Убрать враждебных**, **Убрать животных**, **Убрать предметы и опыт** |

Скорость времени меняется в разах: можно ускорить день или, наоборот, замедлить.

## Ветер

Ветер из раздела **Погода** действует на визуальные эффекты, в которых включён модуль ветра. Обычные блоки и частицы Minecraft он не двигает.

## Пресеты мира

Пресет — это сохранённый набор настроек мира: время, погода и остальное. Его можно применить из этой панели или из сценария:

```sme
story night_mode {
    on time 13000 {
        world_preset("night")
    }
}
```

Кнопка **Копировать команду** рядом с пресетом копирует готовую строку для сценария.

## Быстрые команды в меню

Самое частое есть прямо в меню **Мир**: **Время** (утро, день, ночь), **Погода** (ясно, дождь) и **Режим игры** (творческий, выживание, наблюдатель).

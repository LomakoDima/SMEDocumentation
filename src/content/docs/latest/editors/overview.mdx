Редактор движка открывается клавишей <Kbd>F7</Kbd> прямо поверх игры. Мир при этом не останавливается: вы видите его вживую в центре экрана и меняете на ходу. Повторное <Kbd>F7</Kbd> закрывает редактор.

## Главные части

- **Меню** сверху — все команды редактора: **Файл**, **Правка**, **Вид**, **Проект**, **Инструменты**, **Мир**, **Окна**, **Справка**. Пункт **Сборка** пока пустой — он для будущих версий.
- **Вьюпорт** в центре — ваш мир. Здесь вы летаете камерой, выделяете и двигаете объекты. Подробнее — [Вьюпорт и камера](/docs/latest/editors/viewport).
- **Панели** вокруг вьюпорта. По умолчанию **Сцена**, **Мир**, **Детали** и **История** стоят справа, а **Контент**, **Секвенсер**, **Консоль** и **Диагностика** — внизу. Панели можно открывать, закрывать, перетаскивать и выносить в отдельные окна.
- **Вкладки ассетов.** Когда вы открываете модель, эффект, NPC или сценарий, рядом с вкладкой **Уровень** появляется вкладка этого ассета со своим редактором.

## Панели

| Панель | Для чего |
| --- | --- |
| **Сцена** | список всего, что есть в мире рядом (в радиусе 128 блоков): NPC, модели, зоны, камеры, свет, существа. Можно искать, раскладывать по папкам, скрывать и блокировать объекты. |
| **Детали** | настройки выделенного объекта: положение, поворот, масштаб и его собственные параметры. |
| **Контент** | браузер контента — все модели, текстуры, звуки, эффекты, сценарии и остальное. Подробнее — [Браузер контента](/docs/latest/editors/content-browser). |
| **Мир** | время, погода, режим, точка спавна, граница мира, правила игры. Подробнее — [Настройки мира](/docs/latest/editors/world). |
| **Секвенсер** | таймлайн катсцен и эффектов. |
| **История** | список ваших действий; можно отменять и повторять. |
| **Консоль** | журнал движка и строка для команд вроде `/sme vfx stats`. |
| **Диагностика** | частота кадров, память, сколько всего рисуется, число ошибок. |

Любую панель можно открыть или закрыть через меню **Окна → Панели**.

## Ящик снизу

Панели **Контент** и **Консоль** по умолчанию живут в выдвижном «ящике» внизу экрана. Он не занимает место, пока не нужен.

- <Kbd>Ctrl+Space</Kbd> — открыть или закрыть консоль в ящике.
- **Окна → Ящик: Контент** — открыть браузер контента.

Если ящик мешает, браузер контента можно закрепить в раскладке: в его меню есть пункт **Закрепить в раскладке** (и обратный — **Открепить в ящик**).

## Раскладки и окна

Панели можно перетаскивать за заголовок и ставить рядом друг с другом. Если раскладка сломалась — **Окна → Сбросить раскладку**.

Готовые раскладки — в меню **Окна → Раскладки**:

- **Сцена**
- **Ассеты**
- **VFX**
- **Кинематограф**
- **Скрипты**
- **Широкий вьюпорт**

Свою раскладку можно сохранить через **Окна → Мои раскладки…**. Чтобы случайно ничего не сдвинуть, включите **Окна → Заблокировать раскладку**.

Любую панель можно вынести в отдельное плавающее окно: **Окна → Открепить в окно**. **Окна → Упорядочить окна** раскладывает их аккуратно, **Окна → Закрыть все окна** возвращает панели на место. <Kbd>Ctrl+Shift+Space</Kbd> разворачивает текущую группу панелей на весь экран и возвращает обратно.

## Масштаб интерфейса

Если кнопки слишком мелкие или крупные:

| Клавиша | Что делает |
| --- | --- |
| <Kbd>Ctrl+=</Kbd> | крупнее |
| <Kbd>Ctrl+-</Kbd> | мельче |
| <Kbd>Ctrl+0</Kbd> | вернуть 100% |

Там же, в [настройках движка](/docs/latest/editors/settings), можно выбрать плотность интерфейса — **Просторная** или **Плотная**.

## Полезные клавиши

| Клавиша | Что делает |
| --- | --- |
| <Kbd>F7</Kbd> | открыть или закрыть редактор |
| <Kbd>Ctrl+P</Kbd> | палитра команд — поиск любой команды по названию |
| <Kbd>Ctrl+Z</Kbd> / <Kbd>Ctrl+Y</Kbd> | отменить / повторить |
| <Kbd>Ctrl+S</Kbd> | сохранить открытый ассет |
| <Kbd>Ctrl+W</Kbd> | закрыть вкладку ассета |
| <Kbd>Ctrl+Tab</Kbd> | следующая вкладка |
| <Kbd>Ctrl+R</Kbd> | перезагрузить сценарии |
| <Kbd>Ctrl+,</Kbd> | настройки движка |
| <Kbd>F2</Kbd> | сделать скриншот |

Полный список — в самом редакторе: **Справка → Горячие клавиши**.

## Если нет прав оператора

Редактор меняет мир от имени оператора сервера. Без прав оператора (уровень 2) вы сможете смотреть, но не менять мир. В одиночной игре для этого достаточно включить читы.

**Катсцена** — это сцена, которую игрок смотрит, а не играет: камера сама летит по заданному пути, звучат реплики, появляются субтитры, играют эффекты. Катсцены делаются в панели **Секвенсер**.

## Создать катсцену

1. В браузере контента нажмите **Добавить → Катсцена…**.
2. Введите имя латиницей, например `intro_flyover`, и нажмите **Создать**.

Катсцена откроется в **Секвенсере**. Она сохраняется в `SME Project/data/<ns>/storymodengine/cutscenes`.

## Камера

Путь камеры задаётся **ключевыми кадрами**: в каждом ключе запоминается, где стоит камера и куда смотрит. Между ключами камера плавно летит сама.

1. Поставьте камеру редактора так, как должен выглядеть кадр.
2. Добавьте ключ — **Ключ из вида редактора**.
3. Сдвиньте время на таймлайне, передвиньте камеру и добавьте следующий ключ.

Путь камеры рисуется прямо во вьюпорте (**Путь камеры во вьюпорте**). Кнопка **Смотреть через камеру катсцены** показывает сцену глазами её камеры.

## Таймлайн

| Клавиша | Что делает |
| --- | --- |
| <Kbd>Space</Kbd> | играть / пауза |
| <Kbd>←</Kbd> / <Kbd>→</Kbd> | кадр назад / вперёд |
| <Kbd>Home</Kbd> / <Kbd>End</Kbd> | в начало / в конец |
| <Kbd>F</Kbd> | вписать всё в окно |
| <Kbd>Ctrl+Tab</Kbd> | **Редактор кривых** |
| <Kbd>S</Kbd> | сгладить выбранные ключи |

В **редакторе кривых** видно, как меняется значение со временем, и можно поправить плавность движения: интерполяцию и изинг (ускорение и замедление) ключей.

## Клипы

Кроме камеры, в катсцену добавляются **клипы** — события на отдельных дорожках:

| Клип | Что делает |
| --- | --- |
| **Субтитры** | текст на экране, с говорящим, появлением и исчезанием |
| **Звуки** | звуковое событие; может звучать в точке сцены |
| **Частицы** и **Эффекты** | частицы Minecraft и эффекты из VFX-редактора |
| **Затемнения** | плавное затемнение экрана с заданным цветом и непрозрачностью |
| **Эффекты экрана** | эффекты поверх всего кадра |
| **Видео** | видеоролик в кадре |
| **Записи** | записанная игра — персонажи повторяют то, что делали при записи |
| **Маркеры** | метки на таймлайне с именем |

Клип можно дублировать, вырезать, копировать и удалять через правый клик.

## Записи в катсцене

Записанную игру (см. [Записи (повторы)](/docs/latest/editors/replays)) можно вставить в катсцену как клип **Записи**: персонажи из записи сыграют свои действия. Для клипа выбирается **Главный актёр** и как его снимает камера, например **Камера за актёром**. Записанную анимацию можно **Запечь в ключи** — превратить в обычные ключевые кадры.

Если катсцены ещё нет, проще начать с самой записи: кнопка **Катсцена из записи** создаёт готовую катсцену с записью и камерой — см. [Сделать катсцену из записи](/docs/latest/editors/replays#сделать-катсцену-из-записи).

## Проверить и запустить

- **Сохранить и проиграть в игре** — сохраняет катсцену и сразу показывает её вам как игроку.
- Из сценария катсцена запускается командой `play cinematic`:

```sme
story intro {
    on player enters "village_gate" once {
        play cinematic intro_flyover
    }
}
```

Во время просмотра катсцену можно поставить на паузу или пропустить командами `/sme cutscene pause`, `resume`, `skip`.

## Сохранить в MP4

Кнопка **Рендер в MP4** сохраняет катсцену в видеофайл.

<Screenshot id="editors/cutscene-render" alt="Окно Рендер видео">
Окно «Рендер видео»: разрешение, кадров в секунду, качество, кодировщик, галочки «Со звуком» и «С позиции курсора», имя файла, кнопки «Открыть папку с видео» и «Начать рендер».
</Screenshot>

Выберите **Разрешение**, **Кадров в секунду**, **Качество**, **Кодировщик** (можно оставить **Автоматически**) и **Имя файла**, затем **Начать рендер**.

- **Со звуком** — звук катсцены сводится в файл после рендера.
- **С позиции курсора, а не с начала** — рендер начнётся с того места, где стоит курсор времени.

Видео рендерится покадрово: игра на это время идёт медленнее реального, мир стоит на паузе, интерфейс скрыт. Готовый файл появится в папке игры `sme_renders` — её открывает кнопка **Открыть папку с видео**. <Kbd>Esc</Kbd> отменяет рендер. Для рендера нужен FFmpeg — его движок скачает сам при первом использовании.

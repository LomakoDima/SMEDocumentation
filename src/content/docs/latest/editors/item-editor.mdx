**Редактор предметов** создаёт настоящие новые предметы игры: со своим названием, иконкой или 3D-моделью, свойствами и, при желании, своей логикой в сценарии.

## Создать предмет

1. В браузере контента нажмите **Добавить → Предмет…**.
2. Выберите заготовку: **Пустой**, **Меч**, **Кирка**, **Еда** или **Броня**.
3. Введите имя латиницей — оно станет идентификатором предмета, например `fire_sword`.

Предмет сохраняется в `SME Project/data/<ns>/storymodengine/items/<имя>.json`.

> [!WARNING]
> Новый предмет (или смена его типа) появится в игре **после перезапуска игры** — так устроена регистрация предметов в Minecraft. Редактор подскажет об этом надписью **Нужен перезапуск**. Остальные свойства можно менять без перезапуска.

## Свойства

Свойства разбиты на группы.

| Группа | Что настраивается |
| --- | --- |
| **Основа** | **Название**, **Описание**, **Редкость** (обычный, необычный, редкий, эпический), **Стак** (предметы с прочностью всегда по 1), **Блеск**, **Огнестойкий**, **Тип** |
| **Вид** | иконка `.png` или 3D-модель (glTF/GLB); **Держать как инструмент** |
| **Оружие** | включается галочкой; **Урон**, **Скорость атаки** |
| **Прочность** | **Прочность**, **Зачаровываемость** |
| **Инструмент** | включается галочкой; что это — **Кирка**, **Топор**, **Лопата**, **Мотыга** или **Меч (паутина)**; **Уровень** (**Дерево**, **Камень**, **Железо**, **Золото**, **Алмаз**, **Незерит**), **Скорость копания** |
| **Еда** | включается галочкой; **Сытость**, **Насыщение**, **Можно есть сытым**, **Быстро**, **Пить, а не есть**, а также **Эффект** с **Длительностью**, **Уровнем эффекта** и **Шансом** |
| **Броня** | для типов брони: **Защита**, **Твёрдость**, **Сопр. отбрасыванию**, **Текстура брони** |

**Тип** — это **Обычный предмет** или часть брони: **Шлем**, **Нагрудник**, **Поножи**, **Ботинки**. Смена типа заработает после перезапуска игры.

У 3D-модели отдельно настраивается, как она выглядит в разных местах: в **Инвентаре**, **На земле**, в **Рамке**, **В руке (3-е лицо)**, от **1-го лица** и **На голове**.

## Превью

В центре предмет показан так, как его увидит игрок: **Инвентарь**, **В руке**, **1-е лицо**, **На земле**. Фон превью — **Тёмный**, **Светлый**, **Трава** или **Земля**. Кнопка **/give** кладёт предмет вам в инвентарь, чтобы сразу проверить его в игре.

## Логика

В разделе **Логика** предмету можно написать сценарий: что происходит, когда им пользуются, бьют, копают или едят. Подробнее — [Логика предметов](/docs/latest/sme-scripting/item-logic).

```sme
story relics {
    item storymodengine:healing_charm {
        cooldown 10s
        on use {
            player.heal(6)
            item.damage(1)
        }
    }
}
```

**Браузер контента** (панель **Контент**) — это каталог всего, что есть в игре: ваши файлы из SME Project, ресурсы Minecraft, других модов и пакетов ресурсов. Отсюда вы открываете ассеты в редакторах и ставите их в мир.

По умолчанию браузер прячется в «ящике» внизу экрана. Открыть его — **Окна → Ящик: Контент**.

## Как найти нужное

- **Поиск** — поле «Поиск ассетов…» сверху.
- **Фильтры** — по типу (модель, текстура, звук, эффект, сценарий и т. д.) и по источнику: **Minecraft**, **Моды**, **Ресурспаки**, **SME**.
- **Избранное** — отметьте ассет звёздочкой, а потом включите фильтр **Только избранное**.
- **Вид** — **Сетка** (плитки с превью) или **Список**. Размер плиток меняется в настройках браузера.
- Стрелки **Назад** и **Вперёд** — как в проводнике.

Если ничего не находится, проверьте, не включён ли какой-нибудь фильтр: в меню есть пункт **Сбросить фильтры**.

## Как добавить свои файлы

Самый простой способ — **перетащить файлы из проводника прямо в окно игры**, пока открыт редактор. Движок сам разложит их по нужным папкам SME Project:

| Файл | Куда попадает |
| --- | --- |
| `.glb`, `.gltf` | модели |
| `.png` | текстуры |
| `.ogg` | звуки (звуковое событие создаётся само) |
| `.mp4`, `.m4v`, `.mov` | видео |
| `.ttf`, `.otf` | шрифты |
| `.sme` | сценарии |
| `.nbt` | постройки |
| `.smevfx` | эффекты |
| `.smereplay` | записи игры |

Если перед перетаскиванием открыть в браузере какую-то папку, файл попадёт в неё (если она подходит для этого типа).

Имена файлов при этом приводятся к правильному виду: маленькие латинские буквы и `_`. Например, `My Tree.glb` станет `my_tree.glb`. У модели `.gltf` вместе с ней копируются и её текстуры с файлом `.bin`.

> [!TIP]
> Если положить файл в папку SME Project вручную, а не перетаскиванием, и в его имени будут пробелы или заглавные буквы, игра его не увидит. Редактор это заметит и покажет предупреждение с кнопкой **Исправить имена**.

Второй способ — кнопка **Импорт**: она открывает папку проекта в проводнике.

> [!NOTE]
> Если новый, удалённый или переименованный файл не появился в браузере контента сразу, выберите в меню **Проект → Переиндексировать ассеты** — браузер заново просмотрит все папки, и список обновится.

## Кнопка «Добавить»

Через **Добавить** создаются новые ассеты:

- **Импортировать файлы…** и **Открыть папку ресурспака**
- **Новая папка**
- **VFX-эффект…**
- **Предмет…**
- **NPC…**
- **Вкладка креатива…**
- **Сценарий…**
- **Катсцена…**
- **Рецепт…**
- **Префаб из выделения…** — сохранить выделенные в мире объекты как префаб

Кнопка **Запись** рядом начинает запись игры — подробнее на странице [Записи (повторы)](/docs/latest/editors/replays).

## Что можно сделать с ассетом

**Двойной клик** открывает ассет в его редакторе. Префабы и постройки двойной клик сразу начинает **ставить в мир**. Модели и эффекты ставятся так: перетащите плитку во вьюпорт или выберите **Разместить в мире**.

**Правый клик** по плитке открывает меню:

| Пункт | Что делает |
| --- | --- |
| **Открыть в редакторе** | открыть во вкладке редактора |
| **Открыть в отдельном окне** | открыть редактор в плавающем окне |
| **Разместить в мире** | поставить в мир (для моделей, эффектов, построек) |
| **Копировать ID** | скопировать идентификатор, например для сценария |
| **Переименовать…** (<Kbd>F2</Kbd>) | переименовать вместе со связанными файлами |
| **Дублировать** (<Kbd>Ctrl+D</Kbd>) | сделать копию |
| **Удалить** (<Kbd>Del</Kbd>) | убрать в корзину (после подтверждения) |
| **Показать в проводнике** | открыть папку с файлом |
| **Скопировать в проект** | скопировать чужой рецепт в свой проект, чтобы изменить |

Переименовывать, дублировать и удалять можно только свои файлы из SME Project — файлы Minecraft и других модов браузер не трогает.

Перетащите плитку на папку, чтобы перенести файл.

## Корзина

Удалённые файлы не пропадают сразу, а попадают в корзину. В меню браузера есть пункты **Восстановить последнее удалённое** и **Открыть корзину**. Удаление можно отменить и обычным <Kbd>Ctrl+Z</Kbd>.

## Быстрый просмотр

Если выделить плитку, сбоку появится короткая карточка ассета: ID, пакет, для текстур и построек — размер, кнопка **Открыть редактор**, а для того, что можно поставить в мир, — кнопка **+ Разместить в мире**.

Всё, что можно поставить в мир, собрано в меню **Разместить (Place Actors)**. Откройте его клавишами <Kbd>Ctrl+Shift+A</Kbd> или через **Инструменты → Разместить (Place Actors)…**.

## Как поставить объект

1. Выберите категорию слева и объект справа.
2. Наведите курсор на мир — появится полупрозрачная копия объекта.
3. **Левая кнопка мыши** — поставить. **Esc** или **правая кнопка** — отмена.

Полезные мелочи во время размещения:

| Действие | Что делает |
| --- | --- |
| **Shift + левая кнопка** | поставить и сразу ставить следующий такой же |
| колесо мыши | повернуть объект |
| <Kbd>[</Kbd> / <Kbd>]</Kbd> | уменьшить / увеличить |

Недавно поставленные объекты появляются сверху, в строке **Недавние** — когда поле поиска пустое. Плитки можно показывать **Плитками** или **Списком**.

## Категории

| Категория | Что это |
| --- | --- |
| **NPC** | персонажи: **Пустой NPC** и все шаблоны NPC из вашего проекта |
| **Модель** | любые модели glTF/GLB как неподвижные объекты (пропы) |
| **Префабы** | сохранённые группы объектов |
| **Постройки** | постройки `.nbt` из игры, модов и вашего проекта |
| **Свет** | невидимый источник света заданной яркости (1–15) |
| **Звук** | звук, который играет в этой точке постоянно или с интервалом |
| **Частицы** | обычные частицы Minecraft: огонь, дым, искры, капли, снег и другие |
| **Зона** | невидимая область — коробка или шар. Сценарии реагируют, когда игрок в неё заходит |
| **Триггер** | зона, которая сама выполняет одну строку сценария, когда игрок в неё заходит |
| **Точка пути** | точка, куда можно отправить NPC или игрока; точки можно связывать в маршрут |
| **Камера** | точка съёмки для катсцен и команды `camera_view` |
| **VFX** | эффект из редактора эффектов, который играет в этой точке |
| **Видео-экран** | плоский экран в мире, на котором показывается видео |

Настройки каждого объекта видны в панели **Детали**, когда он выделен. Например, у **Звука** там громкость, тон, дальность и режим, у **Зоны** — форма и размеры, у **Видео-экрана** — само видео, размер, громкость, повтор.

## Постройки

При размещении постройки вместо копии модели появляется «призрак» из блоков — точно так, как постройка встанет.

| Клавиша | Что делает |
| --- | --- |
| колесо мыши или <Kbd>R</Kbd> | повернуть на 90° (<Kbd>Shift+R</Kbd> — в другую сторону) |
| <Kbd>M</Kbd> | отразить зеркально |

В браузере контента и в Place Actors есть фильтр **Без вспомогательных частей**: он прячет мелкие куски построек, из которых игра собирает деревни, и оставляет только целые постройки.

## Как сценарии находят объекты

Зоны, точки пути, камеры и другие объекты сценарии находят **по имени**. Имя задаётся в панели **Детали** или переименованием в панели **Сцена**. Например, если вы назвали зону `village_gate`, сценарий сможет написать:

```sme
story gate_demo {
    on player enters "village_gate" once {
        player.message("Вы подошли к воротам.")
    }
}
```

Подробнее — в разделе [События истории](/docs/latest/sme-scripting/events).

Настройки движка открываются через **Проект → Настройки движка…** или клавишами <Kbd>Ctrl+,</Kbd>. У каждой настройки есть кнопка возврата к значению по умолчанию.

## Интерфейс

| Настройка | Что делает |
| --- | --- |
| **Плотность** | **Просторная** или **Плотная** — сколько места между элементами |
| **Масштаб UI, %** | размер всего интерфейса движка |
| **Заблокировать раскладку** | панели нельзя случайно сдвинуть |
| **Сбросить раскладку** | вернуть панели на места по умолчанию |
| **Раскладка: …** | применить готовую раскладку |

## Вьюпорт

| Настройка | Что делает |
| --- | --- |
| **Скорость камеры** | скорость полёта, блоков в секунду |
| **Привязка к сетке** | двигать и поворачивать с шагом |
| **Шаг позиции**, **Шаг поворота, °** | шаги для привязки |
| **Локальное пространство гизмо** | оси самого объекта вместо мировых (клавиша <Kbd>T</Kbd>) |
| **Пивот по центру выделения** | вращать группу вокруг её центра |
| **Прилипание к поверхности** | объекты прилипают к блокам |
| **Игровой вид** | спрятать помощники редактора (клавиша <Kbd>G</Kbd>) |
| **Предпросмотр камеры**, **Размер предпросмотра** | окно «картинка в картинке» для выделенной камеры |

## Контент

| Настройка | Что делает |
| --- | --- |
| **Объединять кадры текстур** | показывать серию `compass_00…compass_31` одной анимированной плиткой |
| **Размер плиток** | размер плиток в браузере контента |
| **Список вместо сетки** | показывать ассеты списком |
| **Высота ящика, %** | сколько места занимает ящик снизу |
| **Обновить индекс ассетов** | пересобрать список ассетов |
| **Открыть папку ресурспака** | открыть SME Project в проводнике |

## VFX

| Настройка | Что делает |
| --- | --- |
| **Отладка VFX** | показывать статистику и рамки эффектов |
| **Эффекты экрана** | эффекты поверх всего кадра; если выключить, они рисуются простой заливкой |
| **Скрывать интерфейс игры во время эффектов** | прятать хотбар, здоровье, прицел и чат, пока играет эффект экрана |
| **Точка врезки постобработки** | когда рисовать эффекты экрана: **Автоматически**, **Сразу после мира** или **После композита, перед интерфейсом** |

## Игрок

| Настройка | Что делает |
| --- | --- |
| **Модель игрока как у NPC** | игроки рисуются glTF-моделью с анимациями; выключено — обычная модель Minecraft |
| **Тело от первого лица** | от первого лица видно своё тело, руки и ноги |
| **Отступ тела назад** | насколько тело отодвинуто от камеры от первого лица |
| **Продвинутая локомоция (ALS)** | направленные шаги, развороты, старты и стопы, наклоны, постановка ног на ступени и залезание на уступы |
| **Режим поворота тела** | **По взгляду** или **По движению** |
| **IK ног** | ступни встают на ступеньки и плиты |

> [!WARNING]
> **Продвинутая локомоция (ALS)** — экспериментальная функция, она помечена плашкой **Experimental** и по умолчанию выключена.

## Видео

| Настройка | Что делает |
| --- | --- |
| **Скачивать FFmpeg автоматически** | при первом видео один раз скачать декодер (около 25 МБ) |
| **Скачать FFmpeg сейчас** | скачать декодер прямо сейчас, не дожидаясь первого видео |

## Где хранятся настройки

Настройки редактора лежат в папке игры, в `config/storymodengine`. Удалять эти файлы не нужно, но если что-то совсем сломалось, удаление вернёт настройки по умолчанию.

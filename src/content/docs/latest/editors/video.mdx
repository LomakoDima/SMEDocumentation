Движок умеет показывать видео прямо в игре: на экране в мире, в катсцене или по команде сценария.

## Добавить видео

Перетащите файл `.mp4`, `.m4v` или `.mov` в окно игры, пока открыт редактор. Видео попадёт в `SME Project/assets/<ns>/videos`.

> [!NOTE]
> Для видео нужен декодер FFmpeg. Он скачивается сам один раз, когда вы впервые открываете видео (около 20–30 МБ). Подробнее — на странице [Установка](/docs/latest/getting-started/installation#видео).

## Просмотр видео

Двойной клик по видео в браузере контента открывает его в просмотрщике.

## Экран в мире

Чтобы повесить видео в мире, поставьте актёра **Видео-экран** через **Place Actors** (см. [Размещение объектов](/docs/latest/editors/placing)). В панели **Детали** у экрана настраиваются:

| Настройка | Что делает |
| --- | --- |
| **Видео** | какой ролик показывать |
| **Ширина**, **Высота** | размер экрана в блоках (высота 0 — по пропорциям видео) |
| **Состояние** | играет, на паузе или остановлен |
| **Повтор** | крутить по кругу |
| **Громкость**, **Дальность** | насколько громко и на каком расстоянии слышно |
| **Светится** | экран виден и в темноте |
| **Двусторонний** | видно с обеих сторон |

## Видео в сценарии

Экраном можно управлять из сценария по его имени:

```sme
story cinema {
    on player enters "cinema_hall" {
        actor_video_play("cinema_screen")
    }
}
```

Есть также `actor_video_pause`, `actor_video_stop` и `actor_video_seek` (перемотать на нужную секунду) — см. [Справочник команд](/docs/latest/sme-scripting/reference).

## Видео в катсцене

В катсцене видео добавляется клипом **Видео** на таймлайне — см. [Катсцены](/docs/latest/editors/cutscenes).

## Команды

Для проверки видео без редактора есть команды:

| Команда | Что делает |
| --- | --- |
| `/sme video play <источник>` | показать видео поверх экрана |
| `/sme video stop` | закрыть его |
| `/sme video info <источник>` | показать сведения о файле |
| `/sme video stats` | состояние декодера |

Источник — это идентификатор ресурса, например `storymodengine:videos/intro.mp4`, или полный путь к файлу.

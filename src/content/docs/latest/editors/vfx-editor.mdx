**VFX-редактор** делает визуальные эффекты из частиц: огонь, дым, искры, магические вспышки, лучи, шлейфы. Готовый эффект можно поставить в мир, запустить из сценария или добавить в катсцену.

## Создать эффект

1. В браузере контента нажмите **Добавить → VFX-эффект…** (или **Проект → Новый VFX-эффект…**).
2. Введите имя латиницей, например `torch_flame`.
3. Выберите заготовку: **Огонь**, **Дым**, **Искры**, **Магия**, **Взрыв**, **Луч**, **Трейл**, **Mesh-частицы** или **Пустой**.

Эффект сохраняется в `SME Project/assets/storymodengine/sme_vfx`. Открыть существующий эффект — двойной клик по нему в браузере контента.

## Из чего состоит эффект

Эффект состоит из одного или нескольких **эмиттеров**. Эмиттер — это «источник», который рождает частицы. Например, у костра один эмиттер рождает пламя, второй — дым, третий — искры. Кнопка **Добавить эмиттер** добавляет новый.

У выбранного эмиттера настройки идут сверху вниз, в том порядке, в каком они работают:

| Раздел | Что настраивается |
| --- | --- |
| **Эмиттер · жизнь и лимиты** | сколько живёт эмиттер, повторяется ли (**Цикл**), сколько частиц может быть одновременно |
| **Спавн · сколько частиц рождается** | сколько частиц в секунду и вспышками |
| **Форма · где рождаются частицы** | **Точка**, **Сфера**, **Полусфера**, **Круг**, **Сектор**, **Конус**, **Куб**, **Рёбра куба**, **Поверхность модели**, **Молния** и другие |
| **Скорость при рождении** | куда и как быстро летят новые частицы |
| **Модули** | что происходит с частицей за жизнь. Кнопка **+ Модуль** и **Поиск модуля…** |
| **Саб-эмиттеры · частицы из частиц** | частицы, которые рождают новые частицы |
| **Отрисовка** и **Материал** | как частица выглядит: **Спрайт**, **Трейл**, **Луч** или **Модель**; текстура, прозрачность или свечение |

Модули сгруппированы:

- **Движение** — **Гравитация**, **Ускорение**, **Сопротивление**, **Ограничение скорости**, **Орбита**, **Шум**, **Curl-шум**, **Вихрь**, **Притяжение к точке**, **Ветер**, **Ветер мира**, **Лететь к цели**, **Колебание**, **Следовать за эмиттером**;
- **Кривые** — **Цвет по жизни**, **Размер по жизни**, **Прозрачность по жизни**, **Скорость по жизни**, **Цвет по высоте**, **Цвет по скорости**;
- **Мир** — **Столкновение с блоками**, **Столкновение с сущностями**, **Зона гибели**;
- **Вид** — вращение частиц.

Модули выполняются по порядку: те, что выше, работают раньше. Модуль можно выключить галочкой или удалить.

Под деревом эмиттеров — **Эффект: лимиты и параметры**. **Параметры эффекта** — это ручки, которые можно менять снаружи, например из сценария командой `vfx_param`.

## Саб-эмиттеры

Саб-эмиттер — это правило «когда частица делает X, родить из неё другие частицы». Так делаются фейерверки, шлейфы за снарядом и брызги.

| Когда | Пример |
| --- | --- |
| **Рождение** | сопровождение при появлении: вспышка, кольцо |
| **Смерть** | взрыв искр, когда частица гаснет: фейерверк, осколки |
| **Столкновение** | брызги и пыль при ударе о блок |
| **Постоянно** | непрерывно из летящей частицы: дым, искры |
| **По пути** | ровный шлейф: чем быстрее летит, тем гуще |

В правиле выбирается **кого рождать** (другой эмиттер этого эффекта), сколько и с каким шансом. Эмиттер, которого рождают саб-эмиттеры, сам частицы не выпускает.

## Превью

Эффект проигрывается прямо в редакторе.

| Кнопка | Что делает |
| --- | --- |
| **Играть** / **Пауза** (<Kbd>Space</Kbd>) | запустить или остановить |
| **Заново** | начать эффект сначала |
| **Шаг** | один шаг симуляции — удобно разглядывать по кадрам |
| **Зерно** | новое случайное зерно: частицы лягут иначе |
| **Изолировано** / **В мире** | показывать эффект на пустом фоне или прямо в вашем мире |
| **Сюда** | перенести превью к камере |

Включаемые помощники: **Сетка**, **Оси**, **Каркас** (формы эмиттеров), **Габариты**, **Гизмо**.

## Таймлайн

Внизу — **Таймлайн** эффекта: полоса для каждого эмиттера показывает, когда он работает. Задержку и длительность можно двигать мышкой.

## Сохранение и отмена

<Kbd>Ctrl+S</Kbd> — сохранить, <Kbd>Ctrl+Z</Kbd> / <Kbd>Ctrl+Y</Kbd> — отменить и повторить. Если эффект собран с ошибкой, редактор пишет **Эффект не собирается** и объясняет почему.

## Как использовать эффект

- **В мире:** **Place Actors → VFX**, затем выберите эффект. У поставленного эффекта можно задать режим: играть всегда, с интервалом или только по команде сценария.
- **В сценарии:** команды `vfx_play`, `vfx_play_on`, `vfx_stop` и другие — см. [Справочник команд](/docs/latest/sme-scripting/reference).
- **В катсцене:** дорожка эффектов в секвенсере — см. [Катсцены](/docs/latest/editors/cutscenes).

## Отладка

**Инструменты → Отладка VFX** показывает в игре статистику эффектов и их рамки. Это помогает понять, почему эффект не виден или тормозит.

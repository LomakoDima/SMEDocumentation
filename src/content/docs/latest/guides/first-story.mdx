В этом руководстве вы соберёте маленькую, но настоящую историю:

- у ворот деревни стоит **стражник**;
- когда игрок подходит к воротам, он видит сообщение;
- по клику стражник заводит **разговор** и предлагает **задание** — убить трёх зомби;
- после задания стражник благодарит игрока и даёт награду.

Понадобятся мир с включёнными читами и редактор (<Kbd>F7</Kbd>). Если вы ещё не открывали редактор, начните с [Первых шагов](/docs/latest/getting-started/first-steps).

## 1. Создайте стражника

1. В браузере контента нажмите **Добавить → NPC…**
2. В окне **Новый NPC** введите имя в игре — «Стражник», и id латиницей — `guard`. Заготовку выберите **Стражник** и нажмите **Создать**.

<Screenshot id="guides/first-story-new-npc" alt="Окно Новый NPC">
Окно «Новый NPC»: имя «Стражник», id guard, выбрана заготовка «Стражник», пространство имён storymodengine.
</Screenshot>

3. Откроется [редактор NPC](/docs/latest/editors/npc-editor). Во **Внешности** проверьте **Имя** и отметьте **Показывать имя над головой**; если хотите, выберите другую модель.

<Screenshot id="guides/first-story-npc" alt="Шаблон стражника в редакторе NPC">
Редактор NPC, раздел «Внешность» шаблона guard: выделены имя «Стражник» и галочка «Показывать имя над головой».
</Screenshot>

4. В разделе **Взаимодействия** выберите **Нет быстрого действия** — разговор начнёт сценарий.
5. Нажмите <Kbd>Ctrl+S</Kbd>.

> [!NOTE]
> Шаблон получит идентификатор `storymodengine:guard` — по нему сценарий узнаёт этого персонажа. Если при создании вы указали своё пространство имён, вместо `storymodengine` будет оно.

## 2. Поставьте стражника и зону у ворот

1. Откройте **Place Actors** (<Kbd>Ctrl+Shift+A</Kbd>), выберите категорию **NPC**, затем шаблон стражника, и поставьте его у ворот.
2. В той же панели выберите **Зона** и поставьте её перед воротами.
3. Выделите зону и в панели **Детали** задайте имя `village_gate`. Там же подгоните форму и размеры зоны.

<Screenshot id="guides/first-story-zone" alt="Стражник и зона у ворот">
Вьюпорт: стражник у деревянной стены и выделенная зона вокруг входа — оранжевая коробка со стрелками перемещения.
</Screenshot>

## 3. Напишите сценарий

1. В браузере контента нажмите **Добавить → Сценарий…** и назовите его `first_story`.
2. Замените текст в редакторе кода на этот:

```sme
story first_story {

    npc "storymodengine:guard" {
        on interact {
            if quest_done("gate_trial") {
                self.say("Спасибо, {player.name}. Ворота открыты для тебя.")
            } else if quest_active("gate_trial") {
                self.say("Зомби всё ещё бродят у ворот.")
            } else {
                start dialogue guard_intro
            }
        }
    }

    on player enters "village_gate" once {
        player.message("Вы подошли к воротам деревни.")
    }

    dialogue guard_intro {
        Guard: "Стой, путник! По ночам к воротам лезут зомби."

        choice {
            "Я помогу." {
                start quest gate_trial
                jump thanks
            }
            "Не сейчас." {
                end
            }
        }

        node thanks
        Guard: "Убей троих — и я отблагодарю."
        end
    }

    quest gate_trial {
        title "Ночная стража"
        description "Убей трёх зомби у ворот деревни."
        objective kill zombie 3
        reward {
            item emerald 5
            xp 50
        }
    }

    on quest.completed once when quest_done("gate_trial") {
        player.message("Стражник ждёт тебя у ворот.")
    }
}
```

3. Нажмите <Kbd>Ctrl+S</Kbd>. Если внизу, в списке **Проблемы**, пусто — сценарий уже работает.

Редактор кода со сценарием first_story: слева структура (NPC, событие у ворот, диалог, квест), снизу «Проблем не найдено».
</Screenshot>

## 4. Что здесь написано

| Часть | Что делает |
| --- | --- |
| `npc "storymodengine:guard"` | реакции стражника. По клику он смотрит, выполнено ли задание, и отвечает по-разному |
| `on player enters "village_gate" once` | один раз показывает сообщение, когда игрок заходит в зону у ворот |
| `dialogue guard_intro` | разговор: реплика, два ответа, ещё одна реплика |
| `start quest gate_trial` | выбор «Я помогу» начинает задание |
| `quest gate_trial` | само задание: цель — три зомби, награда — изумруды и опыт |
| `on quest.completed` | сообщение после выполнения задания |

## 5. Проверьте в игре

1. Закройте редактор (<Kbd>F7</Kbd>) и подойдите к воротам — появится сообщение.
2. Нажмите на стражника правой кнопкой мыши — начнётся разговор. Выберите «Я помогу».
3. Убейте трёх зомби. Для проверки их можно вызвать яйцом призыва из творческого режима.
4. После третьего зомби задание завершится, вы получите награду, а стражник при следующем клике поблагодарит вас.

<Screenshot id="guides/first-story-ingame" alt="Разговор со стражником в игре">
Разговор в игре: реплика стражника «Стой, путник! По ночам к воротам лезут зомби.» и варианты ответа «Я помогу.» и «Не сейчас.».
</Screenshot>

> [!TIP]
> Команда `/sme quest progress gate_trial` покажет, сколько зомби уже убито. Другие команды — в разделе [Команды /sme](/docs/latest/troubleshooting/commands).

**Сценарий** — это текстовый файл `.sme`, в котором написано, *что* и *когда* происходит в вашей истории. Например: «когда игрок заходит в зону у ворот — начать диалог со стражником» или «когда игрок бьёт этим мечом — поджечь цель».

Всё, что касается *внешности* — модель NPC, его здоровье, поведение, инвентарь, свойства предмета, — настраивается в визуальных редакторах. Сценарии нужны только для **реакций и событий**.

## Как выглядит сценарий

```sme
story village {

    var village.reputation = 0

    npc "storymodengine:guard" {
        on interact {
            village.reputation += 1
            self.say("Привет, {player.name}! Репутация: {village.reputation}")
        }
    }

    on player enters "village_gate" once {
        player.message("Добро пожаловать в деревню.")
    }
}
```

- Всё лежит внутри блока `story имя { … }`.
- `var` — переменная истории, она запоминается вместе с миром.
- `npc "…" { … }` — реакции персонажа.
- `on …` — событие истории.
- Текст после `//` — комментарий, игра его не читает.

## Где писать

Проще всего — в редакторе движка: в браузере контента **Добавить → Сценарий…**. Откроется [редактор кода](/docs/latest/sme-scripting/ide) с подсветкой, подсказками и проверкой ошибок.

Сценарии хранятся в `SME Project/data/<ns>/storymodengine/stories/` в файлах с расширением `.sme`. Их можно писать и в любом текстовом редакторе — после сохранения перезагрузите сценарии клавишами <Kbd>Ctrl+R</Kbd> в редакторе движка или командой `/reload`.

## Как сценарий начинает работать

Нажмите <Kbd>Ctrl+S</Kbd> в редакторе кода — сценарий сохранится и **сразу применится**, перезапускать игру не нужно. Если в сценарии есть ошибки, редактор подчеркнёт их и покажет внизу в списке **Проблемы**, а сломанный сценарий не применится.

Перезагрузить все сценарии разом — <Kbd>Ctrl+R</Kbd> в редакторе.

## Из чего строится история

| Конструкция | Для чего | Подробнее |
| --- | --- | --- |
| `var`, `let`, выражения | числа, текст, проверки | [Переменные и выражения](/docs/latest/sme-scripting/variables) |
| `npc "…" { on … }` | что делает NPC при клике, ударе, смерти, приближении | [Логика NPC](/docs/latest/sme-scripting/npc-logic) |
| `item … { on … }` | что делает предмет при использовании, ударе, копании | [Логика предметов](/docs/latest/sme-scripting/item-logic) |
| `on player enters …`, `on time …` | события истории | [События истории](/docs/latest/sme-scripting/events) |
| `dialogue` | диалоги с выбором ответов | [Диалоги](/docs/latest/sme-scripting/dialogues) |
| `quest` | задания с целями и наградами | [Квесты](/docs/latest/sme-scripting/quests) |
| `shop`, `container`, `trade` | магазины, сундуки, обмен | [Магазины, хранилища и обмен](/docs/latest/sme-scripting/shops) |
| `wait`, `await`, `sequence` | паузы и последовательности действий | [Ожидание и последовательности](/docs/latest/sme-scripting/waiting) |

Список всех действий и свойств — в [Справочнике команд](/docs/latest/sme-scripting/reference).

## Старые сценарии

Если у вас есть сценарии, написанные для старых версий движка, они продолжат работать. Старые формы записи (например, `onInteract { }` вместо `on interact { }`) компилируются, но редактор покажет предупреждение с новым написанием.

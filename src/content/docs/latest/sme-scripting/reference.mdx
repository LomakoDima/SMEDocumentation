Этот список собран из самого движка — это ровно то, что понимает язык SME в текущей версии движка. Те же подсказки показывает [редактор кода](/docs/latest/sme-scripting/ide), когда вы ставите точку после имени объекта.

Как читать таблицы:

- **Свойство** пишется без скобок: `player.name`. Стрелка `→` показывает, что оно возвращает: число (`number`), текст (`text`), да/нет (`bool`) и т. д.
- **Действие** пишется со скобками и параметрами: `player.give("minecraft:bread", 3)`.
- Пометка **можно ждать через `await`** — долгое действие, которого можно дождаться.
- Описания есть не у всех строк: там, где его нет, смысл понятен из названия.

## Функции

Пишутся сами по себе, без объекта: `random(1, 6)`.


| Что | Описание |
| --- | --- |
| `abs(value) → number` |  |

| `distance(a, b) → number` | расстояние между двумя сущностями или точками |
| `floor(value) → number` |  |
| `max(a, b) → number` |  |
| `min(a, b) → number` |  |

## player

Игрок, для которого выполняется сценарий. Кроме этих строк, у игрока есть всё из раздела [entity](#entity).


| Что | Описание |
| --- | --- |
| `add_xp(amount)` | добавить очки опыта |
| `count(item) → number` | сколько таких предметов в инвентаре |
| `give(item, count)` | выдать предметы |
| `has(item, count) → bool` | есть ли в инвентаре не меньше count предметов |
| `level → number` | уровень опыта |
| `message(text)` | сообщение в чат этому игроку |
| `name → text` | ник игрока |
| `play_sound(sound)` | проиграть звук у игрока |
| `sneaking → bool` | игрок крадётся |
| `take(item, count) → bool` | забрать предметы; true, если хватило |

## Команды

Диалог — это разговор, который игрок видит на экране: реплики персонажей и варианты ответа.

```sme
story guard_talk {
    var village.reputation = 0

    dialogue guard_intro {
        Guard: "Стой, {player.name}! Что тебе нужно в деревне?"

        choice {
            "Я пришёл с миром." {
                village.reputation += 1
                jump welcome
            }
            "Не твоё дело." when village.reputation < 10 {
                end
            }
        }

        node welcome
        gate village.reputation >= 0
        Guard: "Тогда добро пожаловать."
        end
    }
}
```

## Из чего состоит диалог

| Строка | Что делает |
| --- | --- |
| `Говорящий: "реплика"` | реплика. Внутри можно подставлять значения: `{player.name}` |
| `choice { … }` | варианты ответа |
| `"текст ответа" { … }` | один вариант и что происходит, если его выбрать |
| `"текст ответа" when условие { … }` | вариант, который виден только при условии |
| `node имя` | метка — начало отдельной части диалога |
| `jump имя` | перейти к метке |
| `gate условие` | если условие не выполнено, диалог заканчивается здесь |
| `end` | закончить диалог |
| `{ … }` | выполнить действия в этом месте диалога |

Внутри варианта ответа — обычные действия сценария: поменять переменную, выдать предмет, начать квест. Заканчивается вариант словом `jump` или `end`.

> [!NOTE]
> Внутри варианта ответа нельзя писать реплику `Говорящий: "…"`. Если после ответа персонаж должен что-то сказать, вынесите реплику в отдельный `node` и перейдите к нему через `jump`.

> [!WARNING]
> Диалог выполняется за один шаг, поэтому внутри него нельзя использовать `wait`, `await` и `call`. Если после диалога нужно подождать или сделать что-то долгое, запустите [последовательность](/docs/latest/sme-scripting/waiting) после диалога.

## Как начать диалог

- Из сценария: `start dialogue guard_intro`.
- Из редактора NPC: в разделе **Взаимодействия** выберите **Начать диалог** и укажите диалог — он будет начинаться по клику на NPC.

```sme
story guard_npc {
    npc "storymodengine:guard" {
        on interact { start dialogue guard_intro }
    }

    dialogue guard_intro {
        Guard: "Чего тебе?"
        end
    }
}
```

## Продолжить реплику

Игрок листает реплики клавишей **Продолжить диалог** (по умолчанию <Kbd>G</Kbd>). Клавишу можно поменять в настройках управления Minecraft, в разделе **StoryModEngine**.

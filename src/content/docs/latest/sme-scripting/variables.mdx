## Переменные истории

Переменная — это ячейка, в которой история что-то запоминает: репутацию, счётчик визитов, был ли уже разговор. Переменные объявляются словом `var` в начале истории:

```sme
story my_story {
    var village.reputation = 0
    var player.has_met_guard = false
}
```

- Переменные **сохраняются вместе с миром** — после перезапуска игры значения на месте.
- Если имя начинается с `player.`, переменная **своя у каждого игрока**. Остальные — общие на весь мир.
- Значение может быть числом, текстом в кавычках или `true`/`false`. Отрицательные числа тоже можно: `var temperature = -5`.

Менять переменную можно прямо:

```sme
story counter_demo {
    var village.reputation = 0

    on time 1000 {
        village.reputation += 1
        village.reputation = village.reputation * 2
    }
}
```

Работают `=`, `+=`, `-=`.

## Временные значения

Внутри обработчика можно завести временное значение словом `let`. Оно живёт только до конца этого обработчика и никуда не сохраняется:

```sme
story let_demo {
    on time 6000 {
        let power = 2 + player.level / 10
        player.message("Сила: {power}")
    }
}
```

## Выражения

- Арифметика: `+` `-` `*` `/` `%`.
- Сравнение: `==` `!=` `>` `<` `>=` `<=`.
- Логика: `and`, `or`, `not` (можно и `&&`, `||`, `!`).
- Скобки — как в математике.

Полезно знать:

- `7 / 2` даёт `3.5`, а `8 / 2` — `4`: дробная часть не теряется.
- `"текст" + 5` склеивается в `"текст5"`.
- Время можно писать в секундах и минутах: `2s` — это 40 игровых тиков, `1m` — 1200.

## Подстановка в текст

Фигурные скобки внутри строки подставляют значение:

```sme
story text_demo {
    var village.reputation = 0

    on time 6000 {
        let emeralds = player.count("emerald")
        player.message("У тебя {emeralds} изумрудов, репутация {village.reputation}")
    }
}
```

Внутри фигурных скобок нельзя писать кавычки. Если значение считается с текстом в кавычках — как `player.count("emerald")`, — сначала сохраните его через `let`, а в строку подставьте имя.

Подстановка работает везде, где есть текст в кавычках: в `self.say(…)`, `player.message(…)`, в репликах и вариантах ответа [диалогов](/docs/latest/sme-scripting/dialogues).

Чтобы написать саму фигурную скобку, поставьте перед ней обратную косую черту: `\{`.

## Условия

```sme
story if_demo {
    var village.reputation = 0

    on time 6000 {
        if village.reputation >= 50 {
            player.message("Тебя тут любят.")
        } else if village.reputation >= 0 {
            player.message("Тебя тут знают.")
        } else {
            player.message("Тебе тут не рады.")
        }
    }
}
```

## Циклы

```sme
story loop_demo {
    on time 6000 {
        repeat 3 {
            player.play_sound("minecraft:block.note_block.bell")
            wait 10
        }
    }
}
```

`repeat N { … }` повторяет блок N раз, `while условие { … }` — пока условие верно.

> [!WARNING]
> Цикл, внутри которого нет ни одного `wait`, движок остановит после 10 000 повторов и напишет ошибку в журнал — чтобы случайный бесконечный цикл не заморозил игру. Если цикл должен крутиться долго, добавьте в него `wait`.

## Полезные функции

| Функция | Что возвращает |
| --- | --- |
| `random(min, max)` | целое число от min до max включительно |
| `chance(percent)` | `true` с вероятностью percent из 100 |
| `min(a, b)`, `max(a, b)` | меньшее и большее из двух |
| `abs(x)`, `floor(x)`, `round(x)` | модуль, округление вниз, округление |
| `distance(a, b)` | расстояние между двумя сущностями или точками |
| `pos(x, y, z)` | точка в мире |
| `waypoint("имя")` | позиция точки пути |
| `npc("имя")` | NPC по имени |
| `nearest("тип", радиус)` | ближайшая к игроку сущность этого типа |
| `quest_done("id")`, `quest_active("id")` | завершён ли квест, идёт ли сейчас |

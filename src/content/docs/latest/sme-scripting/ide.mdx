Сценарии удобнее всего писать во встроенном **редакторе кода**. Он открывается, когда вы создаёте сценарий (**Добавить → Сценарий…**) или открываете файл `.sme` двойным кликом в браузере контента.

## Что он умеет

- **Подсветка** — ключевые слова, строки, числа и комментарии разными цветами.
- **Проверка на лету** — ошибки подчёркиваются сразу, пока вы пишете, а снизу появляется список **Проблемы**. Клик по проблеме переносит к нужной строке.
- **Подсказки** — после точки (`player.`, `self.`, `item.`) появляется список всего, что умеет объект, с параметрами и описанием. Долгие действия, которые можно ждать через `await`, помечены.
- **Структура** — сбоку список того, что объявлено в файле: диалоги, квесты, NPC, события.
- **Переход к объявлению** — встаньте на имя диалога, квеста или последовательности и перейдите туда, где они объявлены.

## Клавиши

| Клавиша | Что делает |
| --- | --- |
| <Kbd>Ctrl+S</Kbd> | сохранить и сразу применить сценарий |
| <Kbd>Ctrl+Space</Kbd> | показать подсказки |
| <Kbd>Ctrl+F</Kbd> | поиск |
| <Kbd>Ctrl+H</Kbd> | поиск и замена |
| <Kbd>F3</Kbd> / <Kbd>Shift+F3</Kbd> | следующее / предыдущее совпадение |
| <Kbd>F12</Kbd> или <Kbd>Ctrl+B</Kbd> | перейти к объявлению |
| <Kbd>Ctrl+Z</Kbd> / <Kbd>Ctrl+Y</Kbd> | отменить / повторить правку |

## Сохранение

<Kbd>Ctrl+S</Kbd> сохраняет файл в SME Project и сразу применяет сценарий в игре. Если в сценарии есть ошибки, файл всё равно сохранится, но редактор предупредит: истории с ошибками не применятся, пока вы их не исправите.

Кнопка **Копировать** копирует весь сценарий в буфер обмена.

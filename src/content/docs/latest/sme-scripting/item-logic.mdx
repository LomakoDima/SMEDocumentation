Свойства предмета — название, урон, прочность, модель — задаются в [Редакторе предметов](/docs/latest/editors/item-editor). Сценарий добавляет **действия**: что происходит, когда предметом пользуются.

```sme
story relics {
    item storymodengine:healing_charm {
        cooldown 10s
        on use {
            if player.health < 10 {
                player.heal(6)
                item.damage(1)
            } else {
                player.message("Ты и так здоров.")
            }
        }
    }

    item storymodengine:ember_blade {
        on hit {
            if chance(30) {
                target.ignite(4)
            }
            target.knockback(0.8)
        }
    }
}
```

После `item` — идентификатор предмета без кавычек.

## События

| Событие | Когда срабатывает |
| --- | --- |
| `on use` | игрок использовал предмет (правая кнопка) |
| `on hit` | игрок ударил кого-то этим предметом |
| `on mine` | игрок сломал блок этим предметом |
| `on eat` | игрок съел предмет |
| `on tick` | постоянно, пока предмет у игрока; как часто — задаётся строкой `tick N` |

`cooldown 1s` — перезарядка: после срабатывания предметом нельзя пользоваться указанное время.

## Кто есть кто

| Имя | Кто это |
| --- | --- |
| `player` | игрок с предметом |
| `item` | сам предмет |
| `target` | тот, кого ударили (в `on hit`) |

## Что может предмет

| Действие или свойство | Что делает |
| --- | --- |
| `item.damage(amount)` | потратить прочность |
| `item.consume(count)` | израсходовать count штук |
| `item.cooldown(ticks)` | перезарядка в тиках (20 = 1 секунда) |
| `item.count` | размер стопки |
| `item.id` | идентификатор предмета |

С целью удара (`target`) работают действия сущностей: `target.ignite(seconds)`, `target.knockback(strength)`, `target.damage(amount)`, `target.effect(effect, seconds, level)` и другие — см. [Справочник команд](/docs/latest/sme-scripting/reference#entity).

> [!NOTE]
> Чтобы у предмета была логика, он должен быть **предметом проекта**, созданным в Редакторе предметов. В его разделе **Логика** есть кнопка, которая сразу открывает нужный сценарий.

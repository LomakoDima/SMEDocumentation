## Что нужно

| | |
| --- | --- |
| Minecraft | Java Edition **1.20.1** |
| Загрузчик | **Forge 47.x** |
| Java | 17 (её ставит любой современный лаунчер) |

Больше ничего не нужно. Все библиотеки, которыми пользуется движок, уже лежат внутри его файла. **Kotlin for Forge ставить не надо** — но если он нужен другим вашим модам, он может спокойно стоять рядом.

## Как поставить

1. Установите Forge 1.20.1 в любом лаунчере (например, в лаунчере Minecraft, Modrinth App или CurseForge).
2. Положите файл `storymodengine-0.1.0-ea-all.jar` в папку `mods` вашей игры.
3. Запустите игру.

## Шейдеры (Oculus)

Движок умеет работать вместе с **Oculus** — модели и эффекты освещаются шейдерпаком. Ничего дополнительно ставить не нужно: если Oculus установлен, движок сам это заметит.

> [!WARNING]
> Раньше для шейдеров нужен был отдельный мод **OculusSMECompat**. Теперь всё встроено в движок. Если этот мод у вас остался в папке `mods`, удалите его — иначе часть функций для шейдеров выключится, а в журнале игры появится просьба его удалить.

## Видео

Чтобы показывать видео (на экранах в мире, в катсценах, в интерфейсе), движку нужен декодер FFmpeg. Он **не входит** в файл мода, чтобы мод весил мало.

Когда вы в первый раз включаете видео, движок сам один раз скачивает FFmpeg для вашей системы (около 20–30 МБ) с Maven Central, проверяет файл и сохраняет его в папке игры `sme_cache/natives/ffmpeg`. Больше он его не скачивает.

Если вы не хотите, чтобы движок что-то скачивал, выключите загрузку в настройках движка: **Видео → Скачивать FFmpeg автоматически**. Без FFmpeg видео просто не будет показываться — всё остальное работает.

## Сервер

Движок нужен **и в клиенте, и на сервере**. На сервер кладётся тот же файл `storymodengine-0.1.0-ea-all.jar`.

Команды движка `/sme …` доступны только операторам сервера (уровень прав 2). Чтобы пользоваться редактором в одиночной игре, включите читы при создании мира.

На этой странице вы откроете редактор, поставите в мир модель и NPC и напишете крошечный сценарий. Это займёт несколько минут.

## Подготовьте мир

Создайте новый мир в творческом режиме и **включите читы**. Редактор меняет мир от имени оператора, и без прав оператора он работает только в режиме просмотра.

## Откройте редактор

Нажмите <Kbd>F7</Kbd>. Поверх игры откроется редактор: в центре — ваш мир (это **вьюпорт**), вокруг — панели.

Ещё один способ — нажмите <Kbd>Esc</Kbd> и в меню паузы нажмите кнопку **SME Editor** в левом верхнем углу.

Чтобы закрыть редактор и вернуться в игру, снова нажмите <Kbd>F7</Kbd>.

## Полетайте камерой

Зажмите **правую кнопку мыши** во вьюпорте — камера начнёт летать:

| Клавиша | Что делает |
| --- | --- |
| <Kbd>W</Kbd> <Kbd>A</Kbd> <Kbd>S</Kbd> <Kbd>D</Kbd> | вперёд, влево, назад, вправо |
| <Kbd>Space</Kbd> или <Kbd>E</Kbd> | вверх |
| <Kbd>C</Kbd> или <Kbd>Q</Kbd> | вниз |
| <Kbd>Shift</Kbd> | лететь быстрее |
| колесо мыши | изменить скорость полёта |

Отпустите правую кнопку — камера остановится. Клавиша <Kbd>Home</Kbd> возвращает камеру к вашему персонажу.

## Поставьте модель

1. Нажмите <Kbd>Ctrl+Shift+A</Kbd> — откроется меню **Разместить (Place Actors)**.
2. Слева выберите категорию **Модель** и нажмите на любую модель.
3. Наведите курсор на место в мире — там появится полупрозрачная копия модели.
4. Нажмите **левую кнопку мыши**, чтобы поставить. <Kbd>Esc</Kbd> отменяет.

Поставленный объект можно выделить кликом и двигать стрелками, которые появятся вокруг него. Подробнее — в разделе [Вьюпорт и камера](/docs/latest/editors/viewport).

## Поставьте NPC

1. Снова откройте **Place Actors** (<Kbd>Ctrl+Shift+A</Kbd>).
2. Выберите категорию **NPC**, затем **Пустой NPC**.
3. Поставьте его в мир левой кнопкой мыши.

Выделите NPC и посмотрите на панель **Детали** справа — там его настройки. Чтобы настроить NPC полностью (имя, модель, поведение, инвентарь), откройте его в [редакторе NPC](/docs/latest/editors/npc-editor).

## Напишите первый сценарий

1. Внизу, в браузере контента, нажмите **Добавить → Сценарий…**
2. Введите имя латиницей, например `my_first_story`, и подтвердите.
3. Откроется редактор кода с готовым примером:

```sme
story my_first_story {

    var my_first_story.visits = 0

    on time 20 once {
        my_first_story.visits += 1
        start dialogue my_first_story_hello
    }

    dialogue my_first_story_hello {
        Narrator: "Hello, {player.name}! This is the story «my_first_story»."
        end
    }
}
```

4. Нажмите <Kbd>Ctrl+S</Kbd>. Сценарий сохранится и сразу начнёт работать — перезапускать игру не нужно.

Этот пример показывает игроку приветствие в момент, когда время суток в мире доходит до 20 (самое начало утра), и только один раз. Если в мире сейчас день, приветствие придёт следующим утром — или переведите время через меню **Мир → Время → Время: утро**. Как устроены сценарии, рассказано в разделе [Сценарии SME](/docs/latest/sme-scripting/overview).

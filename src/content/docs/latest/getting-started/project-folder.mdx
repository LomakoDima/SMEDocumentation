Всё, что вы создаёте в редакторе, — модели, текстуры, звуки, эффекты, сценарии, NPC, предметы, катсцены — сохраняется в одну папку:

```text
<папка игры>/resourcepacks/SME Project
```

Это обычный пакет ресурсов Minecraft. Редактор создаёт его сам при первом сохранении и сам включает. В одиночной игре движок подключает эту же папку и как набор данных мира — поэтому сценарии, NPC и предметы из неё работают сразу.

Открыть папку можно из редактора: меню **Проект → Открыть папку resourcepacks** или кнопка **Импорт** в браузере контента.

## Что где лежит

Внутри две части: **assets** — то, что видит и слышит игрок, и **data** — то, как работает история. `<ns>` — это пространство имён проекта, по умолчанию `storymodengine`. В окнах создания сценария, катсцены, NPC и рецепта его можно указать своё.

| Папка | Что там |
| --- | --- |
| `assets/<ns>/storymodengine/models` | модели glTF и GLB |
| `assets/<ns>/textures` | текстуры (импортированные попадают в `textures/imported`) |
| `assets/<ns>/sounds` и `sounds.json` | звуки `.ogg` |
| `assets/<ns>/videos` | видео |
| `assets/<ns>/sme_vfx` | визуальные эффекты |
| `assets/<ns>/replays` | записи игры (повторы) |
| `assets/<ns>/sme_prefabs` | префабы — сохранённые группы объектов |
| `assets/<ns>/sme_layouts` | макеты из редактора интерфейсов |
| `assets/<ns>/sme_creative` | вкладки творческого режима |
| `assets/<ns>/fonts` | шрифты |
| `data/<ns>/storymodengine/stories` | сценарии `.sme` |
| `data/<ns>/storymodengine/npcs` | шаблоны NPC |
| `data/<ns>/storymodengine/items` | предметы проекта |
| `data/<ns>/storymodengine/cutscenes` | катсцены |
| `data/<ns>/recipes` | рецепты |
| `data/<ns>/structures` | постройки `.nbt` |

Эффекты и префабы всегда сохраняются в пространство `storymodengine`, даже если вы поменяли пространство имён проекта.

Править эти файлы руками не обязательно — для всего есть редакторы. Но знать, где что лежит, полезно, когда вы делитесь проектом или что-то пошло не так.

## Имена файлов

Minecraft принимает только имена из **маленьких латинских букв, цифр и знаков** `_` `-` `.`. Файл с пробелом или заглавной буквой (например, `My Tree.glb`) игра молча пропустит.

Когда вы перетаскиваете файл в окно игры, редактор сам переименует его правильно: `My Tree.glb` станет `my_tree.glb`. Если же вы положили файл в папку руками, редактор заметит неправильное имя и предложит кнопку **Исправить имена**.

## Как поделиться проектом

Чтобы передать свою историю другому игроку, отдайте ему папку `SME Project` целиком. Он кладёт её к себе в `resourcepacks` — и при открытии мира видит всё то же самое.

> [!NOTE]
> Сами объекты, поставленные в мир (NPC, модели, зоны), хранятся в сохранении мира, а не в SME Project. Чтобы передать готовую сцену, передайте и мир, и папку проекта.
